ReeLang

Learn a language the way you already scroll — one short video at a time.

What it is

A language-learning app built around short-form video.

ReeLang turns a vertical video feed into a vocabulary engine. Every clip carries transcribed, translated subtitles, and every word in those subtitles is tappable — one tap looks the word up and files it into your personal vocabulary list.

Saved words then come back to you on a schedule set by the SM-2 spaced-repetition algorithm, the same method behind Anki. Words you find easy drift further apart; words you keep missing return sooner. A background AI agent keeps the feed stocked, searching YouTube for Shorts that match your target language and level.

How it works

Three steps, and the second one takes half a second.

  1. 1

    Watch

    Scroll a vertical feed of short clips in your target language, each one subtitled in the original language and translated underneath.

  2. 2

    Tap

    Hit any word you don't recognise. ReeLang looks up its definition and translation without pausing what you're watching.

  3. 3

    Save

    The word lands in your vocabulary list and enters the SM-2 review queue, resurfacing as flashcards exactly when you're about to forget it.

Tech stack

Two clients, one API, and an agent that feeds them.

Android

  • Kotlin + Jetpack Compose
  • MVVM with ViewModel and StateFlow
  • Room for offline caching
  • Retrofit2 + OkHttp
  • ExoPlayer and the YouTube Player API
  • Firebase Authentication

Web

  • React 18 + TypeScript
  • Vite
  • React Router
  • Firebase Web SDK
  • YouTube IFrame API
  • Deployed on Vercel

Backend

  • FastAPI on Python 3.12
  • PostgreSQL 16
  • SQLAlchemy 2.0 + Alembic
  • Groq Whisper for transcription
  • yt-dlp and deep-translator
  • Cloudflare R2 via boto3
  • Deployed on Railway

AI feed agent

  • Standalone FastAPI microservice
  • APScheduler on a 30-minute cycle
  • YouTube Data API v3
  • Builds a language and level profile per user
  • Fills a per-user feed queue in Postgres
